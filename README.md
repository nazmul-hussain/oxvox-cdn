# oxvox-cdn

Versioned content for the oxvox Flutter app. Served via GitHub raw URLs or jsDelivr:

https://cdn.jsdelivr.net/gh/nazmul-pro/oxvox-cdn@main/v1/manifest.json

Bump `contentVersion` in `v1/manifest.json` whenever data changes. Tag releases (for example `v1.0.0`) to pin versions for old app builds.
See `SCHEMA.md` for the data model.
